# Fonts

Self-hosted so renders never depend on network access.

- `Lora-Variable-latin.woff2`: Lora (Cyreal), SIL Open Font License 1.1
- `Inter-Variable-latin.woff2`: Inter (Rasmus Andersson), SIL Open Font License 1.1

Both are the Latin subsets of the variable fonts served by Google Fonts. They are the same typefaces the BabyDashNow site uses.
